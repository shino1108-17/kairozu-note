# 回路図ノート

実験レポートに貼る回路図を、ブラウザだけで手早く描いてシミュレーションできるエディタです。インストール不要で、データはすべて手元のブラウザ内で処理されます。

**使ってみる:** https://shino1108-17.github.io/kairozu-note/

## できること

- 抵抗・可変抵抗器 (3 端子)・コンデンサ・コイル・変圧器・電池・Vcc 端子・交流／方形波電源・ダイオード・LED・トランジスタ・MOSFET (Nch / Pch)・オペアンプ・モータ・電圧計／電流計などの図記号をグリッド上に配置
- 縦横に自動で折れ曲がる配線と、T 字の分岐点への接続点（黒丸）の自動表示
- 部品を動かすとつながった線も追従
- R1 → R₁ のような下付き表記、JIS（長方形）／ジグザグの抵抗記号、ゴシック／明朝の切り替え
- PNG（1×〜4×、DPI 情報付き）・SVG での書き出し、画像のクリップボードへのコピー
- 作業内容はブラウザに自動保存。JSON ファイルで保存・読み込みもできます

## シミュレーション

ツールバーの「▶ 実行」(⌘/Ctrl + Enter) で、LTspice と同じ考え方（修正節点解析＋ニュートン法）で回路を計算します。

| 解析 | 内容 |
| --- | --- |
| DC 動作点 | 各部品の電圧・電流・消費電力を表で表示。電圧計・電流計には読みが出ます。値やスイッチを変えると自動で再計算 |
| DC スイープ | 電源の電圧（または電流）を少しずつ変えたときの変化をグラフ化。「電源電圧に対する電流」のグラフが作れます |
| 過渡解析 | 時間変化をグラフ化。交流電源・方形波電源の波形、コンデンサの充放電などを確認できます |

- グラフ表示中は「プローブ」で回路の線をクリックすると電圧、部品をクリックすると電流をグラフに追加できます
- グラフは CSV（Excel 用）と PNG で保存できます。線の種類（実線・破線・点線）で見分けるので白黒印刷でも読めます
- LED は「VF (20 mA のとき)」、トランジスタは hFE、MOSFET はしきい値電圧とオン抵抗を、データシートの値で設定できます
- 電圧計は内部抵抗 10 MΩ、電流計は 0 Ω として計算します。半導体は簡単なモデルなので、実測値とは多少ずれます

## 使い方

1. 左の一覧から部品を選び、キャンバスをクリックして配置（`R` 回転、`F` 反転）
2. `W` で配線モード。端子をクリックして始め、別の端子や線に当てると完了
3. 接地記号を置いて「▶ 実行」でシミュレーション
4. 右上の「書き出し」から PNG / SVG 保存、または「画像をコピー」して Word に貼り付け

| キー | 操作 |
| --- | --- |
| `V` / `W` / `T` | 選択 / 配線 / 文字 |
| `R` / `F` | 回転 / 反転 |
| `Delete` | 削除 |
| `⌘/Ctrl + Enter` | シミュレーション実行 |
| `P` | プローブ（グラフ表示中） |
| `⌘/Ctrl + Z` | 元に戻す |
| `⌘/Ctrl + D` | 複製 |
| `⌘/Ctrl + E` | 書き出し |
| `Space` + ドラッグ | 画面の移動 |
| `⌘/Ctrl` + ホイール | ズーム |
| `0` | 全体を表示 |

## ローカルで使う

`index.html` 1 ファイルだけで動きます。ダウンロードしてブラウザで開いてください。
